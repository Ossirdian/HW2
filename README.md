# HW2: Payment System

Учебный проект на Go, который развивается по версиям в ветках `v1`–`v4`.
В версиях последовательно добавляются операции с балансом, переводы между
пользователями и обработка переводов в нескольких workers.

## Требования

- Go версии, совместимой с `go.mod` (указано `go 1.27.2`).

## Запуск

Откройте PowerShell в папке проекта и выполните:

```powershell
go run .
```

Для сборки исполняемого файла под Windows:

```powershell
go build -o hw2.exe .
.\hw2.exe
```

Чтобы запустить другую версию, переключитесь на соответствующую ветку и
выполните команду запуска:

```powershell
git switch v1
go run .
```

Вместо `v1` можно указать `v2`, `v3` или `v4`.

## Версии и ветки

| Ветка | Что реализовано |
|---|---|
| `v1` | Структура `User` и методы `Deposit`/`Withdraw`. В `main` демонстрируются пополнение, успешное списание и ошибка при попытке списать больше доступного баланса. |
| `v2` | Добавлены `Transaction` и `PaymentSystem`, хранение пользователей и очередь переводов. Очередь обрабатывается последовательно; перевод списывает сумму у отправителя и зачисляет получателю. |
| `v3` | Обработка перевода вынесена в `ProcessingTransactions(t)`, добавлен `Worker` с каналом и `sync.WaitGroup`. В `main` запускаются три workers, которым передаются транзакции из канала. |
| `v4` | Добавлен `sync.Mutex` в `User` для синхронизации отдельных операций с балансом: `Deposit` и `Withdraw`. Остальная схема обработки соответствует `v3`. |
